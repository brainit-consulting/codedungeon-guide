Chapter XI

Quick start

Code Dungeon is free and open source, under the MIT licence: github.com/brainit-consulting/codedungeon. It runs on your own computer, and the coders work on your own GitHub projects with your own Claude subscription.

Two short videos show it: Introduction to Code Dungeon (2 minutes 23), what it is and how the guild works, and Getting started (2 minutes 35), installing it and your first project.

What to have ready

  • A Windows 10 or 11 computer. Linux works too; macOS has not been tried yet.
  • Node.js 22 or newer, from nodejs.org.
  • git, from git-scm.com.
  • A GitHub account (github.com) and the GitHub command line, from cli.github.com. Sign it in with gh auth login. Every project in the dungeon lives on GitHub.
  • A Claude subscription, from claude.ai. The coders run Claude Code, which comes with the dungeon; you sign it in once.
  • Google Chrome, from google.com/chrome, so the testers can try your app in a real browser.
  • A Vercel account, from vercel.com, only if you want to put your apps on the internet from the dungeon (chapter VIII).

Install it and start it

Open PowerShell (on Linux, a terminal) in the folder where you keep your projects, and paste this one line:

git clone https://github.com/brainit-consulting/codedungeon.git; cd codedungeon; npm install; npm run login; npm run dev

It fetches Code Dungeon into a folder called codedungeon, installs what it needs (about a minute), signs Claude in (a browser window asks you to allow it), and starts the dungeon. Then open http://localhost:5417 in your browser and press Enter the dungeon. The first time, a short setup asks your name, names your hold and your DungeonMaster, and brings in your first project.

If something is missing, npm run doctor in the codedungeon folder checks Node.js, git, the GitHub command line and the Claude sign-in, and says what to fix.

To walk round with pretend projects and pretend coders first, start it with npm run dev -- --demo instead. Nothing touches GitHub and nothing uses your subscription.

Starting it again

The dungeon runs while its PowerShell window is open. Another day, open PowerShell in the codedungeon folder, run npm run dev, and open http://localhost:5417. Your projects, your guild and your settings are where you left them, in the codedungeon-home folder beside it.

Restarting it

To stop it, press Ctrl + C in its window; that stops the coders' sessions too. To start it again, run npm run dev. When the dungeon restarts by itself, after an update, the coders keep working through it.

Updating it

The ledger's Chambers tab shows when a newer Code Dungeon is on GitHub. To update, stop it with Ctrl + C, then in its folder run git pull; npm install; npm run dev. Your projects, guild and settings stay as they are.
